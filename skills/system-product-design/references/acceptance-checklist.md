# 系统产品设计验收清单

按本次承诺范围检查，每条写证据、失败或「未验证/不适用 + 原因」。设计规格审查、原型测试与真实系统验收分别报告，不能默认打勾。

- [ ] 用户能找到主要任务入口并辨认当前位置。
- [ ] 新建系统有产品内入门：用途/角色、工作流、真实快速开始与结果位置；例外来自明确范围，不暗中省略。
- [ ] 入门可跳过、重开；初次/回访状态按声明保存，已看教程不等于业务完成，正常回访不反复被教学打断。
- [ ] 首项任务能实际完成并找回结果；教程、空状态和帮助与真实入口、权限、字段和状态一致，练习不污染正式数据。
- [ ] 主要模块的对象和职责明确，有必要的检索、详情及操作层级。
- [ ] 关键任务有专用布局，主操作明确且可达。
- [ ] 交付终点与原请求一致；真实接入/上线要求未降为原型，也未擅自扩大发布范围。
- [ ] 模块覆盖表列全承诺的入口、对象、主要任务与实现状态；所有导航可达，每个实现模块的主要任务可用。
- [ ] 待接入模块显示缺口且不计为功能完成；没有空页面或假成功按钮冒充能力。
- [ ] 关键端到端路径在承诺的电脑和手机上分别操作到结果对象，覆盖主要用户与受影响模块。
- [ ] 按实际风险选验异常修复，修复后能继续原任务；不能只挑最容易的路径。
- [ ] 对象、模板或素材在跳转中保持上下文；返回不丢必要选择。
- [ ] 同一对象状态变化后，列表、详情、数量和待办一致。
- [ ] 日常入口按适用任务区分需我处理/等待/阻塞，能解释下一步；结果可检索并查必要来源、变化和有效版本。
- [ ] 有输入的任务说明草稿/保存/提交及存储范围；按声明完成保存→离开/刷新→重开→继续→找回结果。
- [ ] 未保存内容不静默丢失；失败重试、重复点击不会生成重复业务结果。
- [ ] 协作任务完成一次提交→下一位用户队列→处理/退回→原用户继续；模拟身份不当成真实权限。
- [ ] 上传/批量/后台任务适用时检查部分成功、重试和结果定位；无此能力不强加。
- [ ] 手机实际检查导航、工具切换、输入和底部操作；无关键遮挡和意外横向溢出。
- [ ] 电脑实际检查并行区域、表格/列表、详情与编辑操作。
- [ ] 记录实际环境与尺寸，可从手机 375/390、桌面 1440 宽及中间宽度检查；项目要求优先。
- [ ] 双端同一任务的能力差异与限制明确，没有暗中省略手机关键动作。
- [ ] 触摸不依赖 hover；输入时主操作和错误信息可达；焦点、标签和非纯颜色状态可用。
- [ ] 窄屏模拟与真机分开报告；未测手机软键盘/真实触摸不写已通过。
- [ ] 导航、控件和排版层级一致，各模块按任务选择合理布局和信息密度。
- [ ] 空状态、无结果、错误、处理中与缺少必需信息均有可行下一步。
- [ ] 所需语言覆盖动态生成内容和完整关键路径。
- [ ] 真实数据、样例、待登记和待接入可辨；来源和时效在必要处可查。
- [ ] 生成、审核、导出、绑定、发布分别有证据，不凭成功 toast 认定后台完成。
- [ ] 当前交付明确属于设计、可操作原型、已部署或业务验收中的哪一阶段。
- [ ] 改版保留了原数据源、对象标识、有效规则与主要路径，未因换壳损失能力。
- [ ] AI 核心任务说明真实输入、输出对象、人工修订和失败路径；规则判断/动画不冒充 AI 服务。
- [ ] 登录走飞书账号，没有用户名/密码或 Basic Auth；未开通的飞书账号被拒并看到说明；页面、接口、照片/附件、导出都校验登录会话。
- [ ] 多角色或多人编辑适用时验证授权与拒绝路径、直链/搜索/导出范围、并发不静默覆盖；原型明确模拟边界。
- [ ] 长任务或外部数据适用时检查真实进展、过期/失败状态、离开后结果追踪；没有依据不编百分比或“实时”。
- [ ] 真实运行适用时留下启动/恢复、依赖、责任人及现有支持入口，验证承诺的重启和数据恢复；不擅自新建追踪、通知或定时任务。
- [ ] 新人无口头指路试用与设计者自测分开报告；无人参与时只报独立走查，不声称真实用户已会用。
- [ ] 少量效果指标有口径/来源/观察窗；未定目标或未测结果写待确认，不以看完教程或点击次数替代有效任务完成。
